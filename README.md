# 🎯 LeadHunter

**Encontre oportunidades de negócio e potenciais clientes para serviços de desenvolvimento web e mobile.**

O LeadHunter é uma aplicação web desenvolvida para auxiliar freelancers e profissionais de tecnologia na prospecção de clientes. Seu objetivo é identificar empresas locais que podem se beneficiar de soluções digitais, como criação de sites, sistemas web e aplicativos mobile.

A proposta é facilitar a identificação de potenciais clientes e organizar informações que ajudem a encontrar novas oportunidades de negócio.

## 🚀 Objetivo do projeto

Muitos estabelecimentos comerciais ainda não possuem um site próprio ou uma presença digital estruturada. O LeadHunter busca ajudar desenvolvedores a identificar essas empresas e encontrar oportunidades para oferecer seus serviços.

## ✨ Funcionalidades

* 🔎 **Busca de empresas:** pesquisa estabelecimentos por cidade e categoria.
* 🌐 **Identificação de presença digital:** identifica empresas com ou sem site informado nos dados encontrados.
* 📊 **Pontuação de oportunidades:** organiza os potenciais clientes por um indicador de prioridade.
* 🗂️ **Organização de leads:** apresenta informações das empresas em uma interface centralizada.
* 🎯 **Filtros e ordenação:** permite refinar os resultados por categoria, cidade, presença de site e pontuação.
* 📱 **Interface web:** facilita a visualização e a organização dos potenciais clientes.

## 🛠️ Tecnologias utilizadas

* **Frontend:** React, TypeScript e CSS.
* **Backend:** Node.js e Express.
* **Banco de dados:** MySQL/MariaDB.
* **Dados geográficos e comerciais:** OpenStreetMap e API Overpass.
* **Controle de versão:** Git e GitHub.

## 💡 Público-alvo

* Pequenas empresas de desenvolvimento.

## 🔮 Próximos passos

O projeto tem como objetivo evoluir para uma ferramenta mais completa de prospecção, com possibilidades como:

* Integração com inteligência artificial para analisar oportunidades.
* Geração de sugestões personalizadas de abordagem comercial.
* Priorização de leads com base no potencial de negócio.
* Automação de etapas do processo de prospecção.
